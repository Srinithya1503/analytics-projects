================================================================================
LINE-BY-LINE CODE UNDERSTANDING GUIDE
================================================================================
This file decodes analysis.R in plain English so you can explain the logic
confidently in an interview, without needing to re-derive it from scratch.

--------------------------------------------------------------------------------
STEP 1 — set.seed(42)
--------------------------------------------------------------------------------
Ensures that every time you run this code, R generates the exact same "random"
numbers. This is essential for clinical reproducibility: anyone re-running your
script gets identical results, which is expected of rigorous analysis.

--------------------------------------------------------------------------------
STEP 2 & 3 — rnorm(), rpois(), runif()
--------------------------------------------------------------------------------
These are synthetic data generator tools used to simulate realistic patient
characteristics:
- rnorm(n, mean, sd)  -> produces a bell-curve (normal) distribution, used here
  for continuous values like annual treatment cost.
- rpois(n, lambda)    -> models count data (whole numbers), used here for the
  number of hospitalizations per patient. Hospital visits are discrete events,
  not continuous, so a Poisson distribution fits better than a normal one.
- runif(n, min, max)  -> picks values with equal probability across a fixed
  range, used here for the QALY (Quality-Adjusted Life Year) score.

--------------------------------------------------------------------------------
STEP 4 — data.frame(...)
--------------------------------------------------------------------------------
Combines the separate columns (PatientID, Treatment, AnnualCost,
Hospitalizations, QALY) into a single rectangular table called `patient_data`,
the same shape as a spreadsheet — one row per patient.

--------------------------------------------------------------------------------
STEP 5 — patient_data$AnnualCost[patient_data$Treatment == "Drug X"]
--------------------------------------------------------------------------------
This is conditional bracket filtering. Read it right to left:
1. `patient_data$Treatment == "Drug X"` creates a TRUE/FALSE list, one value per
   row, flagging which rows belong to the Drug X group.
2. `patient_data$AnnualCost[ ... ]` uses that TRUE/FALSE list to keep only the
   AnnualCost values where the flag is TRUE.
The same pattern is repeated for the Standard of Care group and for QALY.

--------------------------------------------------------------------------------
STEP 6 — delta_cost / delta_qaly (the ICER formula)
--------------------------------------------------------------------------------
This implements the fundamental health economic formula for an Incremental
Cost-Effectiveness Ratio (ICER):

    ICER = (Cost of Drug X − Cost of SoC) / (QALY of Drug X − QALY of SoC)

It shows the exact financial premium paid for every additional unit of health
gained by switching from Standard of Care to Drug X.

--------------------------------------------------------------------------------
STEP 7 — t.test(Hospitalizations ~ Treatment, data = patient_data)
--------------------------------------------------------------------------------
Asks R whether the drop in hospital visits between the two treatment groups is
likely a real effect of the drug, or could just be random variation. The `~`
symbol means "explained by" — so this reads as "test Hospitalizations, grouped
by Treatment." A small p-value (conventionally < 0.05) suggests the difference
is statistically significant.

--------------------------------------------------------------------------------
STEP 8 — png() / barplot() / dev.off()
--------------------------------------------------------------------------------
Creates a simple bar chart comparing average annual cost between the two
groups and saves it as an image file:
- `png(...)` opens a new image file for drawing.
- `barplot(...)` draws the bars using the group averages calculated earlier.
- `dev.off()` closes and finalizes the image file so it's saved to disk.

--------------------------------------------------------------------------------
STEP 9 — write.csv(patient_data, "patient_dataset_output.csv", row.names = FALSE)
--------------------------------------------------------------------------------
Exports the full simulated dataset to a CSV file so it can be opened in Excel
and used to build the budget_impact_model.xlsx stakeholder tool.
`row.names = FALSE` prevents R from adding an unwanted extra numbering column.
================================================================================
